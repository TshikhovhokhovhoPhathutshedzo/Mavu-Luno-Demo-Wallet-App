# Contributing

Thanks for your interest in contributing to the Mavu / Luno Demo Wallet App. Here are quick guidelines to help you contribute effectively.

- Report issues: open an issue with a clear title, reproduction steps, and expected vs actual behavior.
- Discuss major changes: open an issue or RFC before implementing large features or architectural changes.
- Branches and PRs:
  - Create a topic branch named `feature/<short-desc>` or `fix/<short-desc>`.
  - Keep PRs small and focused; include tests or screenshots as applicable.
- Code style:
  - Follow existing project conventions.
  - Run linters/tests before opening a PR.
- Commit messages: use concise, imperative-style messages (e.g., "Add QR code scanning fallback").
- Tests: add tests for bug fixes and new features when practical.
- Review: be responsive to review feedback; maintainers may request changes before merging.

If you'd like help getting started, comment on an open issue or reach out in the repository's issue tracker.
